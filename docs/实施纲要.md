## 3. 数据模型（DDL 于各模块落地）

| 表 | 关键字段 |
|---|---|
| sys_user | id, username(uk), password(BCrypt), nickname, created_at, updated_at |
| question | id, title, category, tags, difficulty, std_answer, my_answer, source(Preset/Import/Manual), review_count, created_at, updated_at |
| interview | id, company, position, round, interview_date, summary, created_at |
| interview_question | id, interview_id, question_id(nullable), question_snapshot, score(nullable), answered, deduction, my_answer_snapshot |
| review_record | id, question_id, scheduled_at, reviewed_at(nullable), result(Remember/Forgot), next_interval_days, created_at |
| application | id, company, position, city, status, status_updated_at, applied_at, note, created_at |

分类枚举：Java基础 / 并发 / JVM / MySQL / Redis / Spring / 网络 / 操作系统 / 分布式 / 行为面

## 4. 接口约定

- 统一响应 `Result{ code, message, data }`，code=0 成功；错误码集中定义
- RESTful 风格；Knife4j 文档分组；分页参数 page/size；时间 ISO-8601

## 5. 开发规范

- 三层架构 controller / service / mapper；DTO/VO 分离；入参 jakarta validation
- 日志 slf4j；全局异常处理不吞异常
- 前端 ESLint + Prettier；axios 拦截器统一携带 token
- 提交规范：`feat(Mx-y): 描述` / `fix` / `docs`
- 个人面试数据仅存数据库（Docker volume），**不入库**，不 push 到 GitHub
